# Формат импорта JSON

Кодировка файла — UTF-8, максимальный размер — 1 МБ. Корневой объект соответствует следующей структуре:

```json
{
  "schema_version": 1,
  "title": "Название",
  "description": "Описание",
  "settings": {
    "time_limit_minutes": 30,
    "disclosure_policy": "after_deadline"
  },
  "questions": []
}
```

Рабочий пример: [`examples/sample-test.json`](../examples/sample-test.json).

## Вопрос

Обязательные поля:

- `id` — стабильный уникальный ID внутри теста, 1–100 символов `[A-Za-z0-9._-]`;
- `type` — `single_choice` или `multiple_choice`;
- `text` — непустой текст до 5 000 символов;
- `options` — 2–20 вариантов с уникальными `id`;
- `correct_option_ids` — существующие ID правильных вариантов;
- `points` — положительное число;
- `topics` — 1–10 непустых тем;
- `explanation` — подготовленное общее объяснение до 10 000 символов.

У варианта обязательны `id` и `text`; `explanation` необязательно. Для `single_choice` ключ содержит ровно один вариант. Для `multiple_choice` баллы начисляются только за точное совпадение множества выбранных вариантов независимо от порядка.

HTML не поддерживается и отображается как обычный текст. Правильные ответы и объяснения сохраняются в закрытой схеме и не возвращаются API активной попытки.

## Политики раскрытия

- `immediate` — подробный разбор сразу после отправки;
- `after_deadline` — после серверного дедлайна;
- `teacher_released` — после ручного разрешения преподавателя (операция будет добавлена вместе с управлением назначением).
