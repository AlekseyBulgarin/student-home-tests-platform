# API операционной панели

Все вызовы выполняются `POST` в Edge Function `api` с действующим JWT преподавателя. Клиент передаёт только DTO; идентификатор преподавателя извлекается из JWT. Ответы не включают токены назначений, закрытые ключи, объяснения до разрешённого раскрытия или данные другого преподавателя.

| Action | DTO | Серверная гарантия |
| --- | --- | --- |
| `teacher.dashboard` | `{}` | Обновляет истёкшие попытки владельца и возвращает его безопасную операционную проекцию. |
| `teacher.export_attempts` | `search?`, `test_version_id?`, `status?` | Строит CSV только из области текущего преподавателя, нейтрализует формульные префиксы, пишет аудит без PII. |
| `teacher.extend_attempt` | `attempt_id`, `deadline_at` | Только активная собственная попытка; срок можно только сдвинуть вперёд. |
| `teacher.extend_test_attempts` | `version_id`, `deadline_at` | Только собственная версия; меняет только активные неистёкшие попытки. |
| `teacher.force_finish_attempt` | `attempt_id` | Только активная собственная попытка; сервер оценивает текущие сохранённые ответы и ставит `completion_reason=teacher`. |
| `teacher.regrade_attempt` | `attempt_id` | Только завершённая собственная попытка; ответы не меняются, результат строится заново сервером. |
| `teacher.update_grade_scale` | `thresholds[]` | Проверяет упорядоченные пороги на Edge и в БД; не меняет исторические snapshots. |

Все новые DTO валидируются общими Zod-схемами в `supabase/functions/_shared/schema.ts`. RPC-функции доступны только `service_role` и повторяют ownership-проверку по `assignments.teacher_id`.

## CSV

Файл содержит: ученика, тест и версию, статус, прогресс ответов, баллы, процент, оценку, причину завершения, количество событий телеметрии и дедлайн. Телеметрия не интерпретируется как нарушение и не влияет на балл. CSV содержит только текущую отфильтрованную выборку преподавателя.
