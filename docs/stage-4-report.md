# Этап 4 — эксплуатационная готовность

В этапе добавлены: удаление ученика с подтверждением и серверным каскадом, аудит без персональных данных, настраиваемый срок хранения результатов и защищённая серверная задача очистки. Панель преподавателя получила вкладку настроек.

Безопасность усилена CSP и заголовками защиты для API и статического фронтенда. Добавлен GitHub Actions CI: типы, unit-тесты, production-сборка, Playwright и запуск миграций в локальном Supabase на Linux runner.

Ограничение локальной проверки на момент выпуска: Docker Desktop установлен пользователем, но команда `docker` ещё не доступна в текущем терминале. Поэтому миграции подготовлены и запускаются в CI, но локальный контейнерный smoke-test нужно выполнить после перезапуска Docker Desktop/терминала.
