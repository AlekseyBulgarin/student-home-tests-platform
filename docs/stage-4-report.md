# Этап 4 — эксплуатационная готовность

В этапе добавлены: удаление ученика с подтверждением и серверным каскадом, аудит без персональных данных, настраиваемый срок хранения результатов и защищённая серверная задача очистки. Панель преподавателя получила вкладку настроек.

Безопасность усилена CSP и заголовками защиты для API и статического фронтенда. Добавлен GitHub Actions CI: типы, unit-тесты, production-сборка, Playwright, запуск миграций и интеграционный тест БД в локальном Supabase на Linux runner.

Для воспроизводимой проверки реальной БД добавлен `npm run test:db`: сценарий выполняется в локальном Supabase внутри транзакции и откатывается. Он проверяет импорт, публикацию, оценивание, RLS, настройку retention, аудит и каскадное удаление. Для запуска нужен Docker Desktop.
